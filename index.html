Why OpenJ9

Engineered for real-world workloads

OpenJ9 is optimized for cloud, enterprise, and container environments — delivering fast startup, low memory footprint, and sustained throughput.

Fast startup time

Ahead-of-Time (AOT) compilation and shared class caches dramatically cut startup latency, even in containerized workloads.

Low memory footprint

Idle-time optimization, compaction, and container-aware memory management keep heap usage lean — reducing cloud cost.

Flexible GC policies

Choose from multiple garbage collection policies — gencon, balanced, metronome, and more — tuned to your application's workload profile.

JIT compilation

Advanced JIT with GPU offload capability and -Xtune:virtualized mode for maximizing throughput in multi-tenant cloud environments.

Class data sharing

Reduce startup time across multiple JVM instances by sharing class bytecodes and AOT-compiled methods via a persistent shared class cache.

Our Story

Decades of JVM engineering, open source

Eclipse OpenJ9 represents thousands of person-years of engineering effort, powering the IBM SDK, Java Technology Edition, IBM Semeru Runtimes, and many core IBM Enterprise software products.

Contributed in 2017 to the Eclipse Foundation, OpenJ9 continues to evolve through wider community collaboration — driving fresh innovation and shaping the future of the Java platform for enterprise and cloud-native workloads.

Latest Release

Eclipse OpenJ9 v0.62.0

Released September 2026 — supports OpenJDK 27.

What's new in v0.62.0

This release brings several significant improvements to bootstrap class loading, ZIP handling, and platform compatibility.

  • ZIP64 extension support for bootstrap class loading and shared class cache operations, eliminating the previous 4 GB JAR/ZIP size limit.
  • OpenJDK 27 support across all certified platforms.
  • Continued improvements to CRIU (Checkpoint/Restore in Userspace) support for instant-on workloads.
  • Enhanced native cryptographic acceleration through OpenSSL integration updates.

For a full list of supported platforms and OpenJDK versions, see Supported environments.
